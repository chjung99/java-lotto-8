# java-lotto-precourse

## 프로젝트 개요

이 프로젝트는 사용자가 입력한 금액만큼 로또를 발행하고, 당첨 번호와 비교하여 당첨 결과와 수익률을 계산하는 **Java 기반 로또 발매기 프로그램**입니다.

각 로또는 1~45 사이의 중복 없는 숫자 6개로 구성되며, 사용자가 입력한 당첨 번호와 보너스 번호를 기준으로 1등부터 5등까지 당첨 결과를 확인할 수 있습니다.

발행한 로또 번호는 오름차순으로 정렬되며, 구매 금액 대비 수익률을 계산하여 당첨 결과와 함께 출력합니다.

---

## 기능 목록

1. **로또 발행**
    - 사용자가 입력한 금액에 따라 로또 발행 (1장당 1,000원)
    - 구입 금액은 1,000원 단위로 입력해야 하며, 단위가 맞지 않으면 예외 발생
    - 각 로또는 중복 없는 6개의 숫자로 구성, 번호는 오름차순 정렬

2. **당첨 번호 및 보너스 번호 입력**
    - 중복 없는 당첨 번호 6개 입력
    - 당첨 번호는 쉼표(,) 기준으로 구분
    - 보너스 번호 1개 입력
    - 잘못된 입력 시 예외 발생, "[ERROR]" 메시지 출력 후 해당 부분 부터 재입력 받음

3. **당첨 확인**
    - 구매한 로또와 당첨 번호 비교
    - 당첨 등수 및 금액 계산
        - 1등: 6개 번호 일치 → 2,000,000,000원
        - 2등: 5개 번호 + 보너스 번호 일치 → 30,000,000원
        - 3등: 5개 번호 일치 → 1,500,000원
        - 4등: 4개 번호 일치 → 50,000원
        - 5등: 3개 번호 일치 → 5,000원

4. **결과 출력**
    - 발행한 로또 수량 및 번호 출력
    - 당첨 통계 출력 (5등부터 1등까지)
    - 구매 금액 대비 수익률 계산 및 출력 (수익률은 소수점 둘째 자리에서 반올림)

---

## 사용자 흐름

1. 로또 구입 금액 입력
2. 로또 발행
3. 당첨 번호 및 보너스 번호 입력
4. 당첨 통계 및 수익률 확인
5. 프로그램 종료
